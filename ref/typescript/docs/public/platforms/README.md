# Platform artwork

The SVGs in `docs/.vitepress/configurator/logos/` identify platforms in the connection configurator. Platform names and marks belong to their respective owners. dot uses the OpenAI mark; IRC uses an original filled hash symbol for the protocol.

Artwork was extracted from the [Iconify icon sets](https://github.com/iconify/icon-sets) on 2026-10-11. SVG viewboxes are centered on the rendered artwork bounds, with a 20px longest edge inside the shared 24px box. The open shapes of dot, Grok, DingTalk and Feishu use 21px for optical balance. Original aspect ratios are preserved. Foregrounds are monochrome and inverted in dark mode.
