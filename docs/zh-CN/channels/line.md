# LINE

连接 LINE 官方账号，回答私聊、群组和聊天室消息。

## 准备账号

创建具有 Messaging API Channel 的官方账号，将 Channel Secret 和 Access Token 存入接入教程列出的环境变量。将官方账号添加为好友，或邀请到目标群组/聊天室，并检查套餐推送消息额度。

## 在配置器中填写

打开[连接配置器](../connect.md)，选择 **LINE**，填写上一步取得的账号信息。凭据变量名保持默认，按照下载后生成的教程设置实际密钥。将下文取得的发送者 ID 填入「允许使用的用户 ID」，会话 ID 填入「聊天 ID」，有话题时填写「话题 / 线程 ID」，并选择「接收 Agent」。多个允许用户用英文逗号分隔。

将下载的配置保存为 `relanox.json`，并按接入教程在服务器上设置密钥。完成下方的平台连接设置后启动或重启服务，并按「发送第一条消息」验证。手写配置与协议参数见[技术参考](../reference/channels.md#line)。

请机器人管理员准备下面列出的用户和会话 ID，再填写配置。管理员可以从已有的机器人消息记录中核对这些值。使用平台分配的 ID，而非聊天中显示的名称。

「允许使用的用户 ID」填事件中的 `source.userId`。私聊 「聊天 ID」填该用户 ID，群组填 `source.groupId`，聊天室填 `source.roomId`。

## 启用连接

启用 Webhooks，将地址填为 `https://relay.example.com/channels/line-main/webhook`。启动 Relanox 后执行平台回调验证；需要 LINE 重试失败回调时，可启用 webhook redelivery。

## 发送第一条消息

用允许的用户向官方账号或绑定群组/聊天室发送“你好”。官方账号会将回复发到对应会话。

## 图片和文件

提问时可发送图片、音频、视频或文件。图片、音频和视频回复需配置 公网地址，按[媒体](../media.md)通过 HTTPS 对外提供。使用 10 MB 内的 JPEG/PNG 图片。大于 1 MB（1,000,000 字节）的图片及每个 MP4 视频需提供不超过 1 MB 的 JPEG/PNG 预览图。生成音频使用 MP3/M4A 并带时长。音频/视频可到 200 MB，同时受 Relanox 限制。

## 常见问题

回调验证失败时，检查 Channel Secret 和 Access Token 是否属于同一官方账号。群消息缺失时，启用官方账号群组访问并确认它已加入。文字正常而媒体回复失败时，检查 HTTPS 媒体地址、预览图和时长；所有回复都需检查推送额度。
