# IRC

通过专用 IRC 昵称，在频道和私聊中回答文字消息。

## 准备账号

选择支持认证账号标签的 TLS IRC 服务器，注册机器人昵称和账号，将 SASL 密码保存到 `IRC_SASL_PASSWORD`。取得加入所选频道及发言权限。网络另需服务器密码时，填写服务器密码变量名。

## 在配置器中填写

打开[连接配置器](../connect.md)，选择 **IRC**，填写上一步取得的账号信息。凭据变量名保持默认，按照下载后生成的教程设置实际密钥。将下文取得的发送者 ID 填入「允许使用的用户 ID」，会话 ID 填入「聊天 ID」，有话题时填写「话题 / 线程 ID」，并选择「接收 Agent」。多个允许用户用英文逗号分隔。

| 配置器字段     | 填写内容                   |
| -------------- | -------------------------- |
| IRC 服务器域名 | 上一步取得的IRC 服务器域名 |
| TLS 端口       | 初始值：`6697`             |
| 机器人昵称     | 上一步取得的机器人昵称     |
| SASL 账户名    | 上一步取得的SASL 账户名    |

将下载的配置保存为 `relanox.json`，并按接入教程在服务器上设置密钥。完成下方的平台连接设置后启动或重启服务，并按「发送第一条消息」验证。手写配置与协议参数见[技术参考](../reference/channels.md#irc)。

允许发送者填写 `account:<account-name>`，使用用户已认证的网络账号，可从带账号标签的消息或网络账号信息取得。频道 「聊天 ID」使用配置中的准确频道名。私聊绑定使用 `dm:<folded-nick>`，按 IRC 的 RFC1459 规则规范化昵称（小写，并将 `[]\^` 转为 `{}|~`）。例如 Alice 使用 `dm:alice`。

## 启用连接

填写服务器主机名、TLS 端口和昵称。启动后会自动登录，并加入该账号聊天绑定中的频道，无需另填频道列表。保持进程连接以接收新消息。

## 发送第一条消息

登录自己的 IRC 账号，在绑定频道或机器人昵称的私聊中发送“你好”。回答以普通文字行显示，较长回答会拆为多行。

## 图片和文件

IRC 适合文字提问。需要向 Agent 提交图片或文件时，可在[渠道指南](../configuration.md)中选择 Telegram、Discord 或 Matrix 等带附件的渠道。

## 常见问题

消息被过滤时，确认 IRC 客户端已登录网络账号且服务器发送账号标签。机器人无法加入频道时，检查 SASL 凭据和频道权限。
