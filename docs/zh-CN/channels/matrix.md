# Matrix

使用专用 Matrix 账号，在未加密房间和消息串中对话。

## 准备账号

在 Homeserver 创建专用账号/设备并取得 Access Token，保存到 `MATRIX_ACCESS_TOKEN`；邀请账号进入各房间并让其加入，授予发送消息和上传文件权限。

## 在配置器中填写

打开[连接配置器](../connect.md)，选择 **Matrix**，填写上一步取得的账号信息。凭据变量名保持默认，按照下载后生成的教程设置实际密钥。将下文取得的发送者 ID 填入「允许使用的用户 ID」，会话 ID 填入「聊天 ID」，有话题时填写「话题 / 线程 ID」，并选择「接收 Agent」。多个允许用户用英文逗号分隔。

| 配置器字段      | 填写内容                    |
| --------------- | --------------------------- |
| Homeserver 地址 | 上一步取得的Homeserver 地址 |

将下载的配置保存为 `relanox.json`，并按接入教程在服务器上设置密钥。完成下方的平台连接设置后启动或重启服务，并按「发送第一条消息」验证。手写配置与协议参数见[技术参考](../reference/channels.md#matrix)。

允许发送者填写完整 Matrix 用户 ID，如 `@alice:example.com`。从房间信息或房间事件复制内部房间 ID（如 `!support:example.com`）填入 「聊天 ID」。房间别名 `#support:example.com` 与房间 ID 不同。绑定消息串时，「话题 / 线程 ID」填原始 `m.thread` 根事件 ID。

## 启用连接

启动 Relanox 后会自动从 Homeserver 接收消息。保持配置的设备登录有效，并保持 Relanox 运行。使用 HTTPS Homeserver 地址。

官方 [Matrix JavaScript SDK](https://github.com/matrix-org/matrix-js-sdk) 负责同步和重连。SDK 的内存同步游标可能在 Relanox 完成事件入库或附件下载前推进，因此下载失败、进程中断或重启可能留下尚未接收的消息；仍需回答的问题请重新发送。Core 已接受的消息和投递继续保存在配置的数据库中，重启后恢复处理。不支持加密房间和加密附件。

## 发送第一条消息

用允许的账号在绑定的未加密房间发送“你好”。消息串绑定需在该串内回复。专用账号会将 Agent 回答发送到同一房间或消息串。

Agent 可通过 `reply.requestId` 引用指定来信，即使之后又收到新消息也不会改为引用最新消息。不传 `reply` 时不显示消息引用，但仍保留配置的消息串目标。

## 图片和文件

在房间消息中附加图片、音频、视频或文件。生成附件通过 SDK 上传，以原生房间消息显示。Relanox 默认限制单个附件及一条消息的附件合计各为 100 MiB，配置的媒体限制也约束入站下载。上传限制由 Homeserver 决定，这个资源预算不保证平台接受 100 MiB 文件。超限上传会被拒绝，限流会推迟投递；消息发送结果不确定时记录为 unknown，不会按明确拒绝自动重发。

## 常见问题

没有消息到达时，检查账号已加入房间、房间未加密、Token 仍有效。消息串没有回答时，核对根事件 ID。离线或附件下载失败后，检查会话，重新发送尚未到达 Agent 的问题。
