# 修改配置

使用[连接配置器](connect.md)选择聊天软件、机器人和负责回信的 Agent。展开“连接信息”填写所需信息；右侧会同步显示配置。

## 添加聊天或机器人

- **另一个聊天**：在对应账号下点击“添加聊天”，填写聊天 ID，并选择接收 Agent。
- **另一个机器人**：点击“添加同渠道账号”，为它填写独立的账号信息。
- **另一个 Agent**：点击“添加 Agent”，选择 dot、Grok 或 Muse，再把需要的聊天交给它。

聊天和用户 ID 的获取方法见[渠道指南](channels/index.md)。企业微信首次配置可以按指南先[获取聊天 ID](channels/wecom.md)，再回来补全。

## 决定谁可以使用

在“允许使用的用户 ID”里填写可以与机器人聊天的人，多个 ID 用英文逗号分隔。

如果只接入某个话题或帖子，填写它的线程 ID。留空只接收主聊天中的消息，不会自动包含所有话题；需要接入的话题要逐个添加。

多个聊天可以选择同一个 Agent。它可以回复来信所在的聊天，也可以向你分配给它的其他聊天发送消息。

## 填写服务地址和密码

在“公开 HTTPS 地址”中填写你的 Relanox 服务地址，例如 `https://relay.example.com`。dot、Grok 和 Muse 都需要能访问这个地址。地址还没准备好时，先按[部署与备份](operations.md)完成部署。

配置器会生成每个 Agent 的 MCP 密码，也可以自行修改。在“接入教程”中复制密码，并按教程设置服务器上的环境变量。关闭或刷新配置器前请保存好密码。

## 应用修改

配置器每次打开都会创建新配置，不能导入已有文件，刷新页面也会丢失填写内容。修改现有部署时，先备份正在使用的配置，再把需要修改的设置复制进去。保留已有账号 ID、Agent ID 和凭据变量名。

1. 下载生成的 `relanox.json`，与现有配置对照；首次安装可以直接使用下载文件。
2. 按“接入教程”设置新增凭据，校验修改后的配置，再重启 Relanox。
3. 用允许的账号在新增聊天中发送一条消息，确认回信到达。

更换 Agent 密码后，还需按[连接 Agent](agents.md)重新连接。需要手动调整数据库或端口时，查看[配置参考](reference/configuration.md)。
