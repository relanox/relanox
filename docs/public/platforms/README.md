# Platform artwork

These local SVGs identify the platforms in the connection configurator. Platform names and marks belong to their respective owners. dot uses the OpenAI mark; IRC uses a protocol icon.

Assets were extracted from the [Iconify icon sets](https://github.com/iconify/icon-sets) on 2026-10-11. SVG wrappers were added and `currentColor` was fixed to a dark foreground; the UI inverts monochrome artwork in dark mode. Arcticons strokes were increased for readability at 24px.
